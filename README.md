# Online Ednovate Workspace

This repository is now split into two deployable apps.

## Folders
- `frontend/` - Vite + React application
- `backend/` - Node + Express API

## Local Commands
- `npm run dev:frontend`
- `npm run dev:backend`
- `npm run build:frontend`

## Deployment
- Frontend deploy root: `frontend/`
- Backend deploy root: `backend/`

See `SEPARATE-DEPLOY.md` for runtime env setup.
